# Archived dice audition

The app uses synthesized Claves · low. It does not fetch, decode, or bundle any
third-party recording. A fresh clone and production build need no audio files.

An earlier audition used the user-supplied `dice-95077.mp3` from
[Pixabay](https://pixabay.com/sound-effects/film-special-effects-dice-95077/).
Its local copy is ignored by Git to avoid distributing the recording as a
standalone asset in this public repository. It is not part of the application.

The [Pixabay Content License](https://pixabay.com/service/license-summary/)
restricts standalone redistribution. Keep that recording out of version control;
the synthesized replacement removes the need to resolve redistribution rights
for the original recording.
